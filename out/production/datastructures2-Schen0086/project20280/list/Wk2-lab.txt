Q6: What is the difference between a singly linked list and a circularly linked list?
A singly linked list has a clear end: the last node points to null.
In a circularly linked list, the last node points back to the first node, forming a loop with no null reference.

Q7: In what situations would you prefer to use a linked list to an array?
You would prefer a linked list when the size of the data changes frequently and elements are often inserted or removed.
Linked lists allow efficient insertions and deletions without shifting elements, unlike arrays.

Q8: Describe 2 possible use-cases for a circularly linked list.

1. Scheduling
Circularly linked lists are useful in scheduling systems where tasks are processed repeatedly in a fixed order.
After the last task is processed, the scheduler automatically returns to the first task.

2. Multiplayer turn-based games
Circularly linked lists can store players in a game where turns rotate continuously.
Once the last player finishes their turn, the next turn goes back to the first player.
